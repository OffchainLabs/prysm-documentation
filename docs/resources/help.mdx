## Ask for help

- **Discord:** The [Prysm Discord](https://discord.gg/qEZK94mFXP) is the fastest place to ask questions and follow release announcements.
- **Execution client problems:** the team behind your execution client (Besu, Erigon, Geth, Nethermind, Reth…) knows it best, so ask them on their own Discord or GitHub.

## Report a bug

Open an issue on [GitHub](https://github.com/OffchainLabs/prysm/issues/new/choose) using the bug report template. Include your Prysm version (`beacon-chain --version`), operating system, how you run Prysm, the flags you use, and the relevant logs.

## Report a security vulnerability

**Don't open a public issue for a vulnerability.** Follow the [security policy](https://github.com/OffchainLabs/prysm/blob/develop/SECURITY.md): it points to the signed [security.txt](https://github.com/OffchainLabs/prysm/blob/develop/.well-known/security.txt), which lists the reporting address, prysm@offchainlabs.com, and the encryption keys.

## Contribute to Prysm

Prysm is open source. Read [CONTRIBUTING.md](https://github.com/OffchainLabs/prysm/blob/develop/CONTRIBUTING.md) in the Prysm repository for how to set up your environment, test your changes, and submit a pull request. Issues labeled [help-wanted](https://github.com/OffchainLabs/prysm/labels/help-wanted) are a good place to start, and for anything beyond a small fix, open an issue to discuss it first.
